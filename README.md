# Resource Vault

A modern, offline-first resource management app built with Vite, React, TypeScript, Tailwind CSS, and shadcn/ui.

## Features
- Add, search, and organize resources (notes, links, images, files, PDFs)
- Drag-and-drop professional to-do list with reminders
- Custom tags and categories
- Offline support with IndexedDB
- Responsive, accessible UI
- Audio notes, file/image uploads (multiple files supported)

## Tech Stack
- [Vite](https://vitejs.dev/) + [React](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- [Tailwind CSS](https://tailwindcss.com/) + [shadcn/ui](https://ui.shadcn.com/)
- [Radix UI](https://www.radix-ui.com/) primitives
- [IndexedDB](https://developer.mozilla.org/en-US/docs/Web/API/IndexedDB_API) for offline storage

## Getting Started

1. **Install dependencies:**
   ```bash
   npm install
   # or
   yarn install
   ```
2. **Run the app locally:**
   ```bash
   npm run dev
   # or
   yarn dev
   ```
3. **Build for production:**
   ```bash
   npm run build
   # or
   yarn build
   ```
